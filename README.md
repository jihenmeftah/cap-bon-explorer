# Cap Bon Explorer

## Presentation

Cap Bon Explorer est un site web qui permet de decouvrir les activites touristiques de la region du Cap Bon en Tunisie.

## Technologies utilisees

- HTML
- CSS
- Bootstrap
- JavaScript

## Les pages du site

- Accueil : presentation du site.
- Activites : liste des activites avec recherche et filtre.
- Agenda : liste des evenements.
- Reservation : formulaire et calcul du prix.
- Contact : informations et formulaire de contact.

## Fonctionnalites

- Recherche des activites.
- Filtrage par categorie.
- Affichage des details.
- Calcul du prix de reservation.
- Reduction de 10 % pour 4 participants ou plus.
- Verification des formulaires.

## Execution

Ouvrir le fichier `index.html` avec Live Server dans Visual Studio Code.

## Remarque

Ce site est un projet de demonstration. Les reservations ne sont pas reelles.
