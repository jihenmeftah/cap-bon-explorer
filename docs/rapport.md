## 1. Presentation du projet

Cap Bon Explorer est un site web qui presente la region du Cap Bon en Tunisie.

Le but de ce projet est de permettre aux visiteurs de decouvrir les differents endroits de la region et de consulter des informations utiles.

Le site est realise avec HTML, CSS et JavaScript.

## 2. Technologies utilisees

Pour realiser ce projet, j'ai utilise trois technologies principales :

### HTML
HTML permet de creer la structure des pages web. Il permet d'ajouter les titres, les paragraphes, les images et les liens.

### CSS
CSS permet de modifier l'apparence du site. Il permet de choisir les couleurs, les tailles, les espacements et la disposition des elements.

### JavaScript
JavaScript permet d'ajouter des fonctionnalites interactives au site et de rendre la navigation plus dynamique.


## 3. Presentation des pages du site

Le site Cap Bon Explorer contient cinq pages principales :

### 1. Accueil
Presente le projet et la region du Cap Bon.

### 2. Activites
Presente huit activites touristiques avec des informations et des images.

### 3. Agenda
Affiche six evenements dans un tableau.

### 4. Reservation
Contient un formulaire permettant de simuler une reservation et de calculer le prix.

### 5. Contact et FAQ
Contient les informations de contact et les reponses aux questions frequentes.


### Page d'accueil
Elle presente le site et donne une premiere idee sur la region.

### Pages de decouverte
Elles permettent de consulter les informations sur les differents endroits du Cap Bon.

### Navigation
Un menu permet de passer facilement d'une page a une autre.

## 4. Fonctionnalites du site

Le site propose plusieurs fonctionnalites :

- Un menu de navigation pour acceder aux cinq pages.
- Une page activites pour decouvrir les activites disponibles.
- Une page agenda pour consulter les evenements.
- Un formulaire de reservation pour simuler une reservation.
- Une page contact pour envoyer un message.

JavaScript est utilise pour rendre certaines fonctionnalites interactives, notamment le calcul du prix de reservation.

## 5. Tests et conclusion

### Tests
